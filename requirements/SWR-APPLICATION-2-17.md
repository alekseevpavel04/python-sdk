---
itemId: SWR-APPLICATION-2-17
itemTitle: Accept and Store Run Tags
itemHasParent: SHR-APPLICATION-2
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---
System shall accept optional user-provided free-form text tags during application run 
submission and shall store these tags with the run record. The system shall support multiple 
tags per run.
