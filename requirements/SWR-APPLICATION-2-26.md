---
itemId: SWR-APPLICATION-2-26
itemTitle: Generate SDK-Specific Run Metadata
itemHasParent: SHR-APPLICATION-2
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---
System shall automatically generate SDK-specific metadata for each application run including submission date, submission interface (CLI/GUI/API), initiating user information, CI/CD context (when applicable), and test execution markers (when applicable). This metadata shall be immutable after creation.
