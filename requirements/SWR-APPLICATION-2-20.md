---
itemId: SWR-APPLICATION-2-20
itemTitle: Accept and Store Item-Level Tags
itemHasParent: SHR-APPLICATION-2
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---
System shall accept optional user-provided free-form text tags for individual items during application run submission and shall store these tags with the corresponding item records. The system shall support multiple tags per item.
